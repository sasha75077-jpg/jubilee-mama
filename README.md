## ⚠️ ВАЖНО: если ответы перестали приходить

Google отклоняет анонимные отправки (`HTTP 401`), если у формы стоит **«Ограниченный доступ»**.
Гость при этом видит «Спасибо за ответ!», а ответ **молча теряется**.

**Лечение (20 секунд):**
1. Открыть форму → «Поделиться»
2. «Общий доступ» → **«Все, у кого есть ссылка»** (роль: Просмотр или Редактор — неважно)
3. Готово — отправки снова работают

> Проверить в любой момент: `curl -o /dev/null -w "%{http_code}" "<formResponse-url>?entry.571643149=test"`
> Должно быть **200**. Если **401** — доступ закрыт, см. выше.

## 📊 Где смотреть ответы

1. Открыть форму: https://forms.gle/u9WY6FsBBWniYTM4A
2. Вкладка **«Ответы»** — там все ответы (и сводка)
3. Чтобы смотреть как таблицу: в «Ответах» нажать значок **таблицы** → «Создать электронную таблицу»
4. Ответы будут и в Google Sheets (приложение «Таблицы Google» на телефоне), файл можно выгрузить в `.xlsx`

## ✏️ Как изменить

- **Тексты, дата, место** — в `index.html`
- **Цвета, шрифты, отступы** — в `style.css` (палитра в начале файла, переменные `--espresso`, `--cream`, `--sand` и т.д.)
- **Ссылка на форму** — `script.js`, константа `GOOGLE_FORM_URL`

После правок:

```bash
git add -A
git commit -m "Обновление"
git push
```

GitHub Pages пересоберёт сайт за 1–2 минуты.
