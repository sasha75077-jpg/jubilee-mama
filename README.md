# 🎉 Сайт-приглашение на юбилей - 50 лет!

## 📁 Что входит в сайт

- **index.html** - главная страница с приглашением и формой RSVP
- **admin.html** - страница для просмотра ответов гостей
- **style.css** - стили оформления
- **script.js** - функционал формы
- **Мама.jpg** - фотография именинницы

## 🌐 Как разместить сайт в интернете

### Вариант 1: GitHub Pages (БЕСПЛАТНО, рекомендуется)

1. **Создайте аккаунт на GitHub** (если нет):
   - Перейдите на https://github.com
   - Нажмите "Sign up" и зарегистрируйтесь

2. **Создайте новый репозиторий**:
   - Нажмите "+" в правом верхнем углу → "New repository"
   - Название: `jubilee-website` (или любое другое)
   - Поставьте галочку "Public"
   - Нажмите "Create repository"

3. **Загрузите файлы**:
   - Нажмите "uploading an existing file"
   - Перетащите все файлы проекта (index.html, admin.html, style.css, script.js, Мама.jpg)
   - Нажмите "Commit changes"

4. **Включите GitHub Pages**:
   - Перейдите в Settings → Pages
   - В разделе "Source" выберите "main" branch
   - Нажмите "Save"
   - Через 1-2 минуты сайт будет доступен по адресу: `https://ваш-username.github.io/jubilee-website`

### Вариант 2: Netlify (БЕСПЛАТНО, очень просто)

1. Перейдите на https://www.netlify.com
2. Нажмите "Sign up" (можно войти через GitHub)
3. Нажмите "Add new site" → "Deploy manually"
4. Перетащите всю папку с файлами в окно браузера
5. Готово! Сайт сразу доступен по адресу типа `https://случайное-имя.netlify.app`
6. Можно изменить адрес в настройках: Site settings → Change site name

### Вариант 3: Vercel (БЕСПЛАТНО)

1. Перейдите на https://vercel.com
2. Нажмите "Sign up" (можно через GitHub)
3. Нажмите "Add New" → "Project"
4. Перетащите папку с файлами или импортируйте из GitHub
5. Нажмите "Deploy"
6. Сайт будет доступен по адресу `https://имя-проекта.vercel.app`

### Вариант 4: Neocities (БЕСПЛАТНО, для новичков)

1. Перейдите на https://neocities.org
2. Зарегистрируйтесь (бесплатно)
3. Загрузите все файлы через веб-интерфейс
4. Сайт будет доступен по адресу `https://ваше-имя.neocities.org`

## 📊 Как просматривать ответы гостей

### Локально (на вашем компьютере):

1. Откройте файл `admin.html` в браузере
2. Вы увидите все ответы, которые были отправлены с того же устройства
3. **ВАЖНО**: Ответы сохраняются локально в браузере (localStorage)

### После размещения в интернете:

**Проблема**: Текущая версия сохраняет ответы только локально в браузере.

**Решение для получения ответов гостей:**

#### Вариант А: Google Forms (проще всего)
1. Создайте Google Form с аналогичными вопросами
2. Замените форму на сайте ссылкой на Google Form
3. Ответы будут собираться в Google Sheets

#### Вариант Б: Formspree (рекомендуется)
1. Зарегистрируйтесь на https://formspree.io (бесплатно до 50 ответов/месяц)
2. Создайте новую форму
3. Замените в `script.js` код отправки на код Formspree
4. Все ответы будут приходить вам на email + в панели Formspree

#### Вариант В: Telegram Bot
1. Создайте Telegram бота через @BotFather
2. Добавьте код для отправки ответов в Telegram
3. Все ответы будут приходить вам в Telegram

## 🔧 Что нужно добавить перед запуском

### 1. Указать дату мероприятия
Откройте `index.html` и найдите строку 48:
```html
<p id="event-date">Дата будет объявлена дополнительно</p>
```
Замените на конкретную дату, например:
```html
<p id="event-date">15 декабря 2026 года в 18:00</p>
```

### 2. Настроить сбор ответов (важно!)

Если хотите получать ответы от гостей на email:

**Добавьте Formspree:**

В файле `script.js` замените строки 2-20 на:

```javascript
document.getElementById('rsvpForm').addEventListener('submit', async function(e) {
    e.preventDefault();

    const formData = new FormData(this);

    try {
        const response = await fetch('https://formspree.io/f/ВАШ_ID', {
            method: 'POST',
            body: formData,
            headers: {
                'Accept': 'application/json'
            }
        });

        if (response.ok) {
            document.getElementById('rsvpForm').style.display = 'none';
            document.getElementById('successMessage').style.display = 'block';
            document.getElementById('successMessage').scrollIntoView({ behavior: 'smooth' });
        }
    } catch (error) {
        alert('Ошибка отправки. Попробуйте ещё раз.');
    }
});
```

Где взять `ВАШ_ID`:
1. Зарегистрируйтесь на https://formspree.io
2. Создайте новую форму
3. Скопируйте ID формы (будет вида `xyzabc123`)
